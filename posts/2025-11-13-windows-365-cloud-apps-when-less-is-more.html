Windows 365 Cloud Apps: When Less is More

Windows 365 Cloud Apps revolutionize application delivery. Discover how targeted app streaming reduces costs and increases efficiency for SMEs.

Imagine you're the quarterback of your company. Instead of running every play with the entire team, you can throw the perfect pass to the right receiver. That's exactly what Microsoft enables with Windows 365 Cloud Apps – precise application delivery without the unnecessary baggage.

Windows 365 Cloud Apps is generally available. Instead of giving every employee a full virtual desktop, you stream only the apps they really need. Two add-ons are still in public preview: Cloud App support for Autopilot device preparation, and the enhanced user experiences (Snap, full-screen, DPI handling, theming). The result? Less complexity, lower costs, and happier users.

Understanding the Field: What are Windows 365 Cloud Apps?

Windows 365 Cloud Apps work like a well-designed playbook. Administrators can selectively deploy individual applications from the cloud without requiring a full virtual desktop. This strategy is particularly valuable for companies looking to modernize their IT infrastructure while keeping costs under control.

App Streaming from the Cloud

The technical foundation is provided by Windows 365 Flex Cloud PCs (formerly Windows 365 Frontline) in Shared mode. The Microsoft Intune admin center may still show "Frontline" in some places while the rename works its way through. This model is like a shift system in sports – different players use the same equipment at different times. Shared mode is designed for customer-facing workers and external contractors who need a Cloud PC for short, specialised tasks and do not need data persistence. Shift workers and part-time staff who want their own personalised Cloud PC are the use case for Dedicated mode.

One caveat decides whether Shared mode fits at all: when a user signs out of a shared Cloud PC, all user data is deleted. Turn on User Experience Sync (UES) in the provisioning policy if app settings and Windows settings have to survive between sessions.

The Offense: Windows 365 Flex Licensing Model

The Windows 365 Flex licensing model is your strategic advantage — but read the maths before you plan capacity. In Shared mode one licence provisions one Cloud PC that a pool of users shares non-concurrently, and gives you one concurrent session. The maximum number of simultaneous sessions equals the number of Flex licences you allocate to that group: ten simultaneous users need ten licences, not one. Dedicated mode is the other model — one licence, up to three Cloud PCs assigned to three named users, still one active session. That flexibility makes it a good fit for industries with fluctuating staffing needs:

  • Retail: POS systems and inventory management
  • Healthcare: Patient data and scheduling
  • Public Sector: Citizen services and administration

The combination of Flex and Cloud Apps offers a resource-optimized and scalable solution for modern work environments – like a perfectly coordinated team where every player is deployed exactly when needed.

New Plays: Two Enhancements Worth Knowing

Automatic OneDrive Start: Cloud Apps launch OneDrive automatically – but only if the Cloud PC runs a supported build: Windows 11 Enterprise 24H2, or 22H2/23H2 with the 2024-07 cumulative update (KB5040442) or later. On older builds you do not get this, and users wonder why their files are missing.

Enhanced user experiences (public preview): Better Windows Snap and full-screen support, better DPI handling, and refined visuals – borders, shadows, and theme integration. This is the RemoteApp enhancements preview and has to be enabled explicitly.

These make execution easier and more effective. Your employees can focus on what's important, while the technology works smoothly in the background.

The Game Plan: Integration with Intune

That integration has shipped. You can build Cloud Apps from Intune-delivered applications by attaching a Windows Autopilot device preparation policy to the provisioning policy – this part is still public preview. And since July 2026 you can add a Cloud App manually from a file path, which covers legacy apps and apps that never show up in the Start Menu.

Custom images have not gone away: they are still a supported and documented path for custom apps. Autopilot device preparation is the alternative to them, not their replacement. Pick whichever fits how your line-of-business apps are packaged. Like an experienced coach who perfectly tailors his plays to the team.

Centralized Management with Microsoft Intune

Getting in the Game

You need a Windows 365 Flex license. Then you create a Windows 365 provisioning policy and, on the General tab, set Experience to "Access only apps." That selection automatically sets the License type to Flex and the mode to Shared – you cannot combine Cloud Apps with Enterprise licences or Dedicated mode. After that, the apps become available to your users through the Windows App.

Four steps, and do not skip the last one:

  1. Activate License – Assign Windows 365 Flex
  2. Configure Policy – Create a provisioning policy with Experience set to "Access only apps"
  3. Wait for Provisioning – The Cloud PC provisions, and the apps found on its Start Menu appear in All Cloud Apps with the status "Ready to publish"
  4. Publish Each App – Until you publish an app, it does not show up in the Windows App and your users see nothing

The Bottom Line: A Winning Move for Your Business

Windows 365 Cloud Apps mark a paradigm shift in application delivery. Through targeted app streaming and the flexible Flex licensing model, Microsoft offers a solution that is well suited to the dynamic requirements of modern SMEs.

The Intune path is no longer a promise – it is there. For IT decision-makers, this means: less administrative effort, lower costs, and infrastructure that grows with your business. Just do the licence maths first: concurrent sessions equal allocated Flex licences, and in Shared mode user data is gone when the session ends unless you enable User Experience Sync.
